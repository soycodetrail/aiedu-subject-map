## 数据说明

- 三级结构：学科 / 二级知识点 / 具体在线网页；同一知识点可以来自不同网站。
- 发现源：PhET 官方元数据 API、WeduLab 官网实验路由、铜匠开源课程库 catalog、AIedu 台账与访问地图。
- 每条新增链接必须经真实浏览器逐条打开验证；存量链接每日巡检，连续失败并经浏览器复核后才移除。
- 只收录公网在线网址，不含任何本地地址、局域网地址或本地文件路径。
- 铜匠实验室 54 门 3D 课件为开源镜像（CC BY-NC 4.0 署名非商业），原站域名已失效。
- 每日 08:30 由「豆码涌现」自动流水线更新本仓库 `index.html`、飞书云文档与 PDF，并同步一份副本到 words-master-vue 主站模块目录 `public/aiedu-subject-map/`。
